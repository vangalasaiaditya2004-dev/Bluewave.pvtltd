# BlueWave Optimizer

A beginner-friendly full-stack project with:
- React frontend
- Node.js + Express backend
- SQLite database
- JWT authentication

## Run locally

### Backend
```bash
cd server
npm install
npm run dev
```

### Frontend
```bash
cd "BlueWave Aquaculture Pvt. Ltd.front end/latest"
npm install
npm run dev
```

## Production notes
- Set the environment variable `JWT_SECRET` before deploying the backend.
- Set `VITE_API_URL` if the frontend will call a remote backend URL.
- Use `npm start` in the backend for production deployment.
